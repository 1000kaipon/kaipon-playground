# Kaipon Playground

ChatGPTなどで作ったWebゲーム・アプリの置き場です。

- ゲーム: `games/<slug>/index.html` — [GitHub Pagesランチャー](https://1000kaipon.github.io/kaipon-playground/)
- アプリ: `apps/<slug>/index.html` — HTML保管用。GitHub Pagesには公開せず、既存の公開サイトを利用します。
- 設置ルール: [docs/DEPLOYMENT_RULES.md](docs/DEPLOYMENT_RULES.md)

## ゲーム

- **1.2秒後の自分** — 入力した方向へ1.2秒後に移動する、未来予約型ミニゲーム。

## アプリ

- **地球儀 — Globe Lab** — 回転できる地球儀。距離計測・国土の面積比較・図法変換・世界時計。[開く](https://kaipon-globe-lab.qaipon.chatgpt.site) / [HTML・説明](apps/globe-lab/)

## 方針

ゲームの試遊先はGitHub PagesのHTTPS URLとします。既存サイトを持つアプリのGitHub保存時には、新しい公開先を作りません。
