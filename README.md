# Kaipon Playground

ChatGPTなどで作った、小さなWebゲーム・インタラクティブ試作を実際のブラウザで動かすための公開置き場です。

- 公開ランチャー: https://1000kaipon.github.io/kaipon-playground/
- 作品: `games/<slug>/index.html`
- 設置ルール: `docs/DEPLOYMENT_RULES.md`

## 現在の作品

- **1.2秒後の自分** — 入力した方向へ1.2秒後に移動する、未来予約型ミニゲーム。

- **地球儀 — Globe Lab** — 回転できる地球儀。距離計測・国土の面積比較・図法変換・世界時計。[開く](https://1000kaipon.github.io/kaipon-playground/games/globe-lab/) / [説明](games/globe-lab/README.md)

## 方針

ChatGPTの添付HTMLやiOSのQuick Lookを最終実行環境にせず、GitHub Pages上のHTTPS URLを正規の試遊URLとします。
