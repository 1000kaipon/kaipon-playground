# 地球儀 — Globe Lab

- 公開・利用URL: https://kaipon-globe-lab.qaipon.chatgpt.site
- 移植元: Sites v23 / `ecb62944439f2a675560a226063e8a42a616f6c3`
- GitHubへの配置日: 2026-10-11

`index.html` だけで動作する地球儀です。地図、国データ、CSS、JavaScript、背景、雲の保存画像を内包しています。ダウンロードしたHTMLをブラウザで開くこともできます。

## 機能

- 全方向の慣性回転、国・地域の選択、首都の発光表示
- 国名・面積・人口・GDP・公用語・首都・Wikipediaリンク
- 距離計測、国土コピーの移動、左右の同縮尺面積比較
- 地球儀・メルカトル・イコールアース・正距円筒・ランベルト正積方位図法
- 世界時計、昼夜表示、ランダムな地球ツアー
- 配色変更、海氷・雲・夜間光の保存データ、横スクロールする宇宙背景

## 保存用HTMLの扱い

このディレクトリはHTMLの保管用です。GitHub Pagesには公開せず、利用先は上記のSites版とします。保存用HTMLにはSites版のサーバーAPIは含まれません。雲は起動時に同梱の日時付き保存画像を表示し、SSEC RealEarthへの直接接続に成功すれば取得画像へ切り替えます。CORS制限・通信エラー・タイムアウト時は保存画像（取得後は最後に取得した画像）を維持します。成功後は1時間ごと、失敗後は15分後に再試行します。「更新を確認」で手動更新もできます。航空機・船舶は引き続き休止中です。

国データ、海氷、夜間光もリアルタイム情報ではありません。統計年や画像時刻、出典、地図の計算上の制約はアプリ内の「データ出典」「使い方」を参照してください。

地図描画と球面計算にはD3、地図データの展開にはTopoJSONを使用しています。両ライブラリはHTMLに同梱しており、起動時のCDN取得は不要です。原データ・ライブラリの権利は各提供元に帰属します。

## 起動と操作

下部の「● READY」は地図データの初期化が完了したことを示します。PCではドラッグで回転、ホイールまたは＋／−で拡大縮小。タッチ画面ではドラッグと＋／−を使います。表示領域が狭いときは設定メニューや国データの「詳細」を開けます。
